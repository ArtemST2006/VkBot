# Бот розыгрышей для VK

## О проекте

Это демонстрационный бот для сообщества ВКонтакте по [ТЗ](TASK.md), которое изначально описывает бота для MAX. Каждый день акции посвящён одному партнёру: пользователь может получить промокод, участвовать в розыгрыше его приза и накопить шанс на главный приз. Состояние акции хранится в PostgreSQL.

## Использование

Бот планируется запустить на моём сервере 25 октября 2026 года. Один демонстрационный цикл рассчитан на 10 дней. После его окончания я очищу Docker volume и запущу бот снова: миграции создадут новый календарь партнёров с даты запуска.

Чтобы протестировать бота, подпишитесь на [моё сообщество VK](https://vk.ru/club242443821), нажмите «Сообщение» и отправьте `Начать` или `/start`. В чате можно проверить основные сценарии, описанные ниже.

## Логика работы

1. **Начало.** Пользователь отправляет `Начать` или `/start`. Бот сохраняет его, показывает приветственный баннер и меню.
2. **Партнёр дня.** Для каждой даты акции по московскому времени в базе задан один партнёр, приз и запас промокодов. Бот находит партнёра по текущей дате.
3. **Промокод.** По кнопке «Получить промокод» бот закрепляет за пользователем один свободный код текущего дня. Повторное нажатие возвращает тот же код.
4. **Ежедневное участие.** Кнопка «Участвовать в розыгрыше» сразу создаёт одну заявку на текущий день. Повторное нажатие показывает существующую заявку. Ссылки на аккаунты партнёров демонстрационные.
5. **Шансы.** Получение кода или подача заявки делают день активным. Оба действия в один день дают один шанс, всего можно накопить до 10 шансов.
6. **Розыгрыши.** Фоновая задача раз в минуту ищет завершившиеся по московскому времени дни и один раз выбирает победителей и резерв из зарегистрированных участников. После последнего партнёрского дня проводится финальный розыгрыш с учётом накопленных шансов. После простоя бот обработает пропущенные дни при запуске.
7. **Уведомление и приз.** Победитель получает сообщение с кнопкой «Получить приз». Бот запрашивает имя и фамилию и отдельное согласие на передачу данных. Если победитель не подтвердит получение в течение 72 часов после доставки сообщения, приглашение перейдёт следующему участнику из резерва.

## Допущения и решения вне ТЗ

- **Платформа.** Вместо MAX используется VK Bots Long Poll: бот сам получает события сообщества, поэтому публичный адрес и webhook не нужны.
- **Часовой пояс.** Партнёрский день определяется по московской календарной дате. Тестовый промокод действует до конца этого дня; розыгрыш проводится после его завершения.
- **Длительность демонстрации.** Миграция создаёт 10 последовательных партнёрских дней с даты первого применения по московскому времени. Финальный розыгрыш проводится после десятого дня.
- **Демоданные.** Для каждого дня есть пять тестовых промокодов. Ссылки ведут на `example.com`; реальные покупки и выдача призов не предусмотрены.
- **Срок ответа.** Для победителя установлен срок 72 часа с момента доставки уведомления. В ТЗ срок не указан.

### Отличия демоверсии от ТЗ

- Подписка на партнёра не проверяется: нажатие кнопки участия сразу регистрирует заявку.
- Результаты розыгрышей не проходят ручное подтверждение администратора перед отправкой уведомлений; выгрузки для организаторов и партнёров нет.
- Данные статистики доступны по команде `/stats`, но отдельной панели аналитики нет. Бот отправляет сообщения победителям, произвольной массовой рассылки нет.
- Имя победителя и согласие сохраняются в базе, но автоматической передачи данных партнёру или билетному оператору и реальной выдачи приза нет.

## Запуск

Понадобятся Docker Compose и сообщество VK. В сообществе должны быть включены сообщения, возможности ботов и Bots Long Poll с событиями `message_new` и `message_event`. Нужны токен сообщества с правами на сообщения и числовой ID сообщества.

```sh
cp .env.example .env
```

В `.env` замените `VK_GROUP_TOKEN` и `VK_GROUP_ID` на свои. Значение `VK_ADMIN_ID` из примера тоже замените на свой числовой ID профиля VK; если статистика не нужна, оставьте `VK_ADMIN_ID` пустым (подробнее описано ниже в разделе про статистику). `DATABASE_URL` из примера нужен для запуска с хоста; контейнер бота использует адрес `postgres` внутри Docker Compose.

```sh
docker-compose up --build -d
docker-compose logs -f vkbot
```

Контейнер дождётся PostgreSQL, применит миграции через `goose` и запустит бота. Бот и PostgreSQL имеют политику `restart: unless-stopped`. Данные сохраняются в Docker volume при обычном перезапуске или `docker-compose down`.

Для нового демонстрационного цикла с первым партнёром текущего дня можно удалить прежний volume и запустить проект заново:

```sh
docker-compose down -v
docker-compose up --build -d
```

Команда `down -v` удаляет данные предыдущего цикла: пользователей, коды, заявки, результаты розыгрышей и статистику.

## Отдельно про статистику для организатора

После заполнения `VK_ADMIN_ID` отправьте `/stats` в личные сообщения сообщества с этого профиля. Бот покажет общее число запустивших его пользователей, запросы и выдачи промокодов, новых пользователей по дням акции, остаток кодов и участников розыгрыша у каждого партнёра. Повторные запросы промокода в день акции тоже учитываются. Команда не отображается в общем меню и недоступна другим пользователям. Если `VK_ADMIN_ID` пуст, она отключена.

Фрагмент ответа (числа условные):

```text
Статистика акции
Запустили бота: 12
Запросы промокода: 18
Выдано промокодов: 9

Новые пользователи по дням акции (МСК):
25.10: 7

Партнёры по дням:
25.10 — Демо: Кофейня: промокодов осталось 2, участников розыгрыша 5
```

## Что проверить в чате

Откройте сообщения своего сообщества и отправьте `Начать` или `/start`. Бот сохранит пользователя и покажет приветствие с [баннером](internal/vkbot/assets/welcome.png) и кнопками. Если VK не примет фото, бот отправит текстовое меню.

| Кнопка | Что произойдёт |
| --- | --- |
| «Получить промокод» | Выдаст один свободный код партнёра текущего дня. Повторное нажатие покажет тот же код. |
| «Участвовать в розыгрыше» | Сразу создаст одну заявку на день и покажет партнёра с призом. |
| «Мои шансы» | Покажет активные дни, партнёров и число шансов на главный приз. |
| «Как участвовать» | Объяснит механику акции. |
| «Правила акции» | Покажет краткие условия демоверсии. |

Получение кода **или** заявка дают один шанс за день. Если сделать оба действия, второй шанс не добавится. Всего можно накопить до 10 шансов. Закончившиеся промокоды не мешают подать заявку.

## Что внутри

Путь события: **VK Bots Long Poll → обработчик кнопки → сервис → PostgreSQL**. Ответы уходят через VK API. Отдельные фоновые циклы проводят розыгрыши и отправляют сообщения победителям из очереди.

- `cmd/vk-bot` — запуск бота и фоновых задач.
- `internal/vkbot` — работа с VK, обработчики кнопок и закрытая команда статистики.
- `internal/service` — правила участия и получения приза.
- `internal/storage/postgres` — SQL-запросы.
- `migrations/` — схема, 10 партнёрских дней и хранение розыгрышей.
